# آکادمی نحو

پروژه آغازین اندروید با Kotlin و Jetpack Compose.

## ساخت APK
این مخزن دارای گردش‌کار GitHub Actions است. پس از بارگذاری فایل‌ها در شاخه `main`،
از زبانه Actions گردش‌کار `Build Android APK` را اجرا کنید.
فایل خروجی در بخش Artifacts با نام `nahw-academy-debug-apk` قرار می‌گیرد.

## نکته علمی
محتوای فعلی صرفاً نمونه اولیه رابط و درس است. شرح مستند ابن عثیمین باید جداگانه
از PDF منبع استخراج و بازبینی شود و مطالب آموزشی افزوده به ایشان نسبت داده نشود.
